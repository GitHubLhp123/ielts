## 数据结构

### 核心状态

- groups: 分组列表
- projectColumns: 项目列列表，包含 groupId、width、targetValue
- noteFields: 复盘字段列表
- tableData: 学习记录表数据
- todoItems: Todo 数据
- bookkeepingEntries: 记账数据
- bookkeepingCategories: 记账分类
- recurringRules: 周期记账规则
- reminderConfig: 提醒配置

### 学习记录行结构

- id
- date
- durationMinutes
- metrics
- notes

### 记账记录结构

- id
- time
- amount
- item
- category
- reason
- isDraft
- generatedFromRuleId

## 功能关联审查

### 关联正确

- 学习记录表 -> Overview: 今日缺失项、趋势摘要、风险项目、最近复盘都来自表格数据，关联正确。
- 学习记录表 -> 学习统计: 趋势图、热力图、时长图均由表格数据驱动，关联正确。
- 学习记录表 -> 复盘信息展览表: 复盘字段直接复用 noteFields 和 tableData，关联正确。
- Todo -> Overview / 记录建议: 待办数量、待办列表、建议文案都来自 todoItems，关联正确。
- 记账本 -> Overview / 记账日历 / 图表 / PDF: 支出摘要、日历聚合、周月图、类别图、PDF 统计均来自 bookkeepingEntries，关联正确。
- 导入导出 -> 全页状态: groups、projectColumns、noteFields、tableData、todoItems、bookkeepingEntries、recurringRules、reminderConfig 都进入快照，关联正确。

### 已修复的断链

- 行复制方法原本已存在，但界面没有入口，属于交互断链。本次已补齐表格操作按钮。
- 图表目标点标记方法原本已接入图表配置但为空实现，导致“低于目标”没有可视反馈。本次已补齐。

### 需要注意但未扩改的点

- 排序方式当前只有“日期升序”一种选项，界面预留了扩展位，但并未形成多排序能力。
- 导入内容只做了必要字段校验，当前更偏向受控使用场景，不是严格模式的外部数据校验器。
- 页面依赖公网 CDN，离线或 CDN 不可用时页面会受影响。
