# 语料库 Release Notes

## 版本
- 发布名称：语料库雅思单词听写 v2.1
- 发布日期：2026-04-28
- 发布类型：维护发布

## 发布摘要
本次发布以“功能审查、稳定性修复、交互收口”为主，没有改动语料数据本身，重点解决导出命名、备份提醒、默认值一致性和配置控件误操作问题。

## 本次变更
- 导出学习记录文件名更新为“语料库学习记录备份-时间戳.json”。
- 错词导出文件名更新为“语料库错词导出-时间戳.csv”。
- 首次进入页面时，如果尚未备份，会主动弹出备份提醒。
- 设置恢复时，播放间隔默认值统一回到 2 秒。
- 听写模式下自动禁用“听音顺序”“单词循环次数”两个仅属于听音模式的控件。
- 答案输入框关闭自动大写和拼写检查，减少英文输入干扰。
- 增加 warning 状态视觉反馈。
- 下载对象 URL 延迟释放，提升导出稳定性。
- 页面标题和主标题统一补充“语料库”前缀。

## 审查结论
- 核心功能可用：章节选择、单词校验、错词本、章节统计、导入导出、音频缓存链路完整。
- 关键联动正确：章节切换可自动填充词表，模式切换可同步调整控件可用性。
- 数据关联正确：错词本、单词统计、章节统计之间的关联关系未发现断链。
- 安全性总体可控：未发现高风险脚本注入或明显本地数据破坏漏洞。

## 已知问题
- 外部音频服务仍依赖第三方 HTTP 源，部分浏览器环境下可能出现播放失败、缓存失败或网络受限问题。
- 由于上游 HTTPS 证书存在主机名不匹配，当前不适合直接切换到 HTTPS 地址。

## 使用建议
- 首次使用或清理数据前，优先导出一份学习记录备份。
- 若需要长期稳定使用，建议后续提供本地音频镜像或可替换音频源配置。
- 若页面部署到 Web 服务器，建议同步评估音频源可达性与浏览器安全策略。
