# 语料库版本信息

## 基本信息
- 产品名称：语料库雅思单词听写练习页
- 主文件：王璐语料库_源码.html
- 审查日期：2026-04-28
- 当前版本：v2.1
- 版本性质：功能审查 + 交互优化 + 稳定性修正

## 功能清单
- 章节选择与自动填充：按章节装载语料库单词，并同步当前练习列表。
- 手动单词输入：支持粘贴单词列表，自动去重、清理空行、转小写。
- 语料库匹配校验：自动识别不在语料库或不在所选章节的单词，并在开始前移除。
- 听写模式：播放音频、提交答案、记录正确次数、错误次数、错词本和单词统计。
- 听音模式：只播放音频，支持顺序或随机播放，并支持每词循环次数设置。
- 练习流程控制：开始、暂停、重播、显示答案、手动下一题、只练错词。
- 错词本：章节筛选、勾选、反选、按错误率/错误次数/最近时间排序、单词发声、删除、导出 CSV、直接开始练习。
- 章节统计：记录完整章节练习结果，展示历史记录与正确率曲线。
- 本地持久化：保存设置、错词本、单词统计、章节统计和音频缓存。
- 数据备份迁移：导出 JSON 备份、导入预览、导入覆盖恢复。
- 音频缓存：优先读缓存，缺失时联网拉取并写入 IndexedDB。
- 二次确认：清空错词本、章节统计、练习统计、音频缓存前弹窗确认。

- 章节选择 -> 单词填充 -> 练习列表刷新：已验证正常。
- 练习模式切换 -> 听音专属控件可用性切换：已验证正常。
- 导出学习记录：已验证文件名带“语料库”前缀。
- 错词本、章节统计、单词统计之间的数据关联：逻辑闭环完整。
- 完整章节统计写入条件：仅在听写模式、按章节、完整章节练习完成后写入，逻辑正确。
- 导入逻辑：具备版本迁移、结构清洗和导入预览，关联关系正确。

## 本轮已修复问题
- 修复首次使用时备份提醒不会出现的问题。
- 修复导出学习记录和错词导出文件名未带“语料库”前缀的问题。
- 修复设置回退时播放间隔默认值与界面默认值不一致的问题，将回退值统一为 2 秒。
- 优化下载实现，避免创建的 Blob URL 过早释放导致下载不稳定。
- 增加 warning 反馈样式，避免部分提示状态缺少视觉区分。
- 在默认听写模式下禁用听音专属控件，减少误操作。
- 优化答案输入框，关闭自动大写与拼写检查，降低英文输入干扰。
- 页面标题与主标题统一纳入“语料库”命名。

## 交互优化结论
- 默认听写模式下，听音顺序和循环次数已禁用，状态更清晰。
- 首次进入页面会主动提示用户导出备份，降低本地数据丢失风险。
- 反馈区、库校验提示、导入预览、清空确认的分层清晰，主流程可理解性较好。
- 错词本的筛选、勾选和直接练习链路完整，适合复习场景。

## Bug 与漏洞审查结论
- 未发现高风险前端注入漏洞。页面中的用户输入和导入内容主要通过 textContent 写入，确认弹窗消息也做了白名单过滤。
- 未发现会直接破坏本地存储结构的明显逻辑漏洞，导入流程对 settings、mistakeBook、wordStats、chapterStats 均有清洗处理。
- 未发现错词本、章节统计和单词统计之间的主键冲突问题。

## 已知边界与残留风险
- 远程音频源仍依赖 http://www.1kao.com.cn，属于外部站点依赖。在更严格的浏览器或部署环境下，可能受混合内容、跨域策略或上游服务可用性影响。
- 目标站点当前 HTTPS 证书存在主机名不匹配问题，因此不能直接安全切换为 HTTPS 源。
- 音频缓存是否成功，仍受浏览器对远程音频抓取和跨域返回头的支持情况影响。

## 建议的后续版本方向
- 提供可配置的音频源地址或本地音频包，摆脱单一第三方站点依赖。
- 为主要流程补一组自动化冒烟测试，覆盖章节切换、开始练习、备份导入导出和错词复练。
- 将版本号、发布日期和更新摘要直接展示在页面内，便于非技术使用者确认版本。
